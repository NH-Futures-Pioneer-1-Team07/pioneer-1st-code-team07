# 삼성전자선물 3틱 역매매 전략

전략 판단은 [전략 문서](../../../docs/strategies/week-02/samsung-futures-reversal-3tick.md)를 따른다. 기존 두 전략과 별개로 등록되며 연구용 `experiments` 모듈을 불러오지 않는다.

완성된 3분봉으로 고저점·후보·회복 확인·목표 갱신을 판단한다. 진입 의도는 상태에 보관하고, 확인 직후 첫 1분 구간의 첫 가격 콜백에서 손절·목표 범위와 최소 목표거리3틱을 검사한 뒤 시장가 주문을 한 번 낸다. 조회 지연이 있어도 그 구간 안이면 검사하지만 다음 분 이후에는 폐기한다. 시장가 실제 체결가는 주문 전 관측 가격과 다를 수 있으므로 실제 체결 후에도 목표거리3틱을 보장하는 규칙은 아니다.

`manifest.json`의 선택적 `backtest` 설정이 관측1분봉 가격 재현을 지정한다. 신호는3분봉 그대로 받고 손절·익절·마감 전 가격 감시와 평가액은1분자료로 재현한다. 신호봉과1분봉의 OHLCV가 맞지 않으면 오류로 종료하며3분봉 실행으로 대체하지 않는다. 없는 분의 가격은 합성하지 않는다. 실시간 모의운용은 기존 플랫폼의 `on_price` 체결가격 콜백을 사용한다.

서버를 시작하면 화면의 전략 선택에 **삼성전자선물 3틱 역매매 전략**이 나타난다. 백테스트와 모의매매가 같은 `Strategy` 클래스를 사용한다. 새 전략 추가가 자동으로 모의계좌 주문을 시작하지는 않는다.

마감·최종거래일 청산은 실제 잔여 수량이 없어져야 완료로 처리한다. 미체결·처리 여부 미확인 청산 주문이 이미 보호하는 수량은 다시 주문하지 않는다. 거부·취소 후 보호되지 않은 잔여 수량은 가격 콜백에서5초 간격으로 다시 청산한다.

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_reversal_3tick_strategy.py tests/test_minute_backtest.py tests/test_reversal_3tick_service.py -q
```

테스트는 합성 봉과 임시 기록 디렉터리를 사용하며 외부 API나 별도 연구 캐시가 필요하지 않다. 최소 목표거리 경계, 첫 가격 확인 시한, 목표 갱신, 마감 청산, 1분 가격 재현과 서비스 등록을 검증한다. 총보유량 상한·일손실 한도 등 미확정 방어 규칙은 추가하지 않았다.
