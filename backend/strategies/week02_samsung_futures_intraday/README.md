# 삼성전자선물 장중 전략

- 판단 규칙: [samsung-futures-intraday.md](../../../docs/strategies/week-02/samsung-futures-intraday.md)
- 구현: [strategy.py](strategy.py)
- 파라미터: [manifest.json](manifest.json). 이름과 기본값은 전략 문서 10절과 같다.

## 호출 방식

- `on_bar`: 3분봉이 마감될 때마다 호출한다. 신호 판단, 시각 규칙, 초과분 진입 기한 확인을 한다.
- `on_price`: 장중 가격이 갱신될 때 호출한다. 신호는 판단하지 않고 시각 규칙과 초과분 진입만 처리한다.
- 같은 봉에는 `on_bar`를 한 번만 호출해야 한다.
- 시작·재시작 전에 이미 발생한 신호로 주문하지 않으려면, 호출하는 쪽이 시작 이후 완성된 봉만 `bars`에 넣어야 한다.

## 구현 해석

전략 문서에 없는 부분을 다음과 같이 정했다.

| 항목 | 해석 |
| --- | --- |
| 봉 범위 | `ctx.bars` 중 `ctx.now`와 같은 날짜의 봉만 쓴다. 전일 봉은 무시한다. |
| 평균 거래량 | 신호 봉을 뺀 당일 직전 `volume_avg_bars`개 봉의 평균이다. 당일 봉이 모자라면 신호를 건너뛴다. |
| 추세 비교 | 최근 `trend_compare_count`개 고점이 모두 높아지고 저점도 모두 높아지면 상승, 모두 낮아지면 하락이다. 개수가 2이면 문서의 정의와 같다. |
| 반대 신호 청산 순서 | 오래된 진입분부터 청산한다. |
| 반대 신호 초과분 | 전량 청산을 낸 뒤 상태에 `pending_flip`을 남긴다. 기한은 판단 시각에서 `bar_minutes × order_valid_bars`분 뒤다. 기한 전에 `on_price`에서 보유분과 미체결 주문이 없으면 초과분을 진입한다. |
| 기한 경계 | 기한 시각 이후에는 초과분을 진입하지 않는다. 신호 다음 봉이 마감되는 시각이 기한이므로, 호출하는 쪽은 그 봉 안에서 `on_price`를 한 번 이상 호출해야 한다. |
| 미체결 주문 | `open_orders`가 비어 있지 않으면 새 신호를 건너뛴다. 상태가 불확실한 주문도 `open_orders`에 포함해 전달해야 한다. |
| 신규 진입 제한 시각 | 처음 호출될 때 `open_orders`를 모두 취소하고, 취소한 청산 주문의 남은 수량을 청산 주문으로 다시 낸다. 호출하는 쪽은 취소를 먼저 처리한 뒤 주문을 전송해야 한다. |
| 당일 청산 시각 | 처음 호출될 때 `open_orders`를 모두 취소하고 모든 보유분의 청산 주문을 낸다. 같은 날 다시 청산하지 않는다. 청산 상태 확인과 재시도는 이 전략이 하지 않는다. |
| 최종거래일 | `last_trading_day`가 오늘이면 신규 진입을 하지 않고, 보유분이 있으면 처음 호출될 때 청산 주문을 낸다. `last_trading_day`가 `None`이면 신규 진입을 하지 않는다. |
| 판단 기록 | 호출마다 결과를 남긴다. 신호가 있으면 매수·매도, 신호가 없으면 보류, 신호를 건너뛰면 건너뜀과 이유를 남긴다. 점수는 쓰지 않는다. |

## 상태

`ctx.state`와 `StrategyOutput.state`로 다음을 주고받는다. 날짜가 바뀌면 초기화한다.

- `day`: 상태가 속한 날짜
- `entry_count`: 오늘 낸 진입 주문 수. 진입분 id(`<날짜>-<번호>`)에 쓴다.
- `pending_flip`: 반대 신호 초과분(방향, 수량, 기한)
- `cutoff_done`, `flatten_done`, `final_exit_done`: 시각·날짜 규칙을 오늘 이미 처리했는지
