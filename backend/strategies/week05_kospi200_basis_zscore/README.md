# 코스피200 베이시스 z-score 전략

- 전략 문서: [week05_kospi200_basis_zscore.md](../../../docs/strategies/week05_kospi200_basis_zscore.md)

## 구현 메모

- 종목은 코스피200 선물 `A016C000`(2026년 12월물)이다. 월물이 바뀌면 `manifest.json`의 `code`를 바꾼다. 기록이 남은 뒤에는 폴더를 복사해 새 이름으로 만든다.
- 매니페스트의 `index_code`(`KRD020020016`, 코스피200 지수)가 있으면 러너가 지수 5분봉을 같이 받아 선물 봉의 `Bar.reference`에 같은 시작 시각의 지수 종가를 넣는다(`app/runners/basis.py`). 백테스트·조합 탐색은 로더, 모의매매는 브로커가 붙인다. 체결과 손익은 선물 가격으로 계산한다.
- 입력: 5분봉(`history_bars`로 전날까지의 봉 300개를 이어 받음), 계약당 증거금(`margin`), 보유분 평가손익.
- 증거금(`margin`) 40,463,850원은 2026-11-18 모의환경 `품목별세부정보`의 계약당 개시증거금이다. 값은 `manifest.json`에 고정하므로 가격 수준이 크게 바뀌면 갱신한다.
- 지수 봉이 없는 봉, 신호 시간(09:00~15:20) 밖의 봉은 z-score 이력에 쓰지 않는다.
- 수익률 청산(`exit_return_pct`)은 이익과 손절에 같은 값을 쓴다. 판단은 확정 5분봉 종가 기준이다.
- 판단 기록의 `detail`에는 베이시스·z-score·직전 봉 z-score·유효 봉 수·보유·증거금 대비 수익률이 남는다.
- 백테스트 가능 기간 조회(`range`)는 선물 분봉만 본다. 지수 분봉이 더 짧으면 그 구간은 판단하지 않는다.
