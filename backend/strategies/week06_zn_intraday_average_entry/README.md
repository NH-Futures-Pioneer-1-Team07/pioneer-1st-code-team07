# 6주차 ZN 당일 평단 기준 추가 진입 전략

[전략 명세](../../../docs/strategies/week06_zn_intraday_average_entry.md)와 [3주차 구현](../week03_zn_treasury_futures/)을 따른다. 신규 진입 체결은 청산과 별도로 기록하며, 그날의 매수·매도 평단은 모의매매의 판단 화면에 표시한다.

백테스트에서 추가 진입 지정가는 교차 직후 이어지는 같은 날짜의 5분봉만 평가한다. 봉이 유리한 가격에서 시작하면 슬리피지를 지정가 한도 안에서 적용한다. 봉 안에서 지정가에 닿으면 지정가에 체결된 것으로 계산한다.

모의매매에서는 지정가를 NH에 제출하고 시한에 취소한다. NH 주문 요청에 만료 시각을 넣을 수 없으므로, 취소 확인 전에 거래소에서 체결된 주문은 실제 체결로 반영한다.
