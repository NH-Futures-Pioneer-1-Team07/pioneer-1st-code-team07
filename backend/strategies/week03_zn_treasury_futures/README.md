# ZN 미국 10년 국채선물 이동평균 전략

- 전략 문서: [week03_zn_treasury_futures.md](../../../docs/strategies/week03_zn_treasury_futures.md)

## 구현 메모

- 종목은 `ZNZ26`(CME, 거래소 코드 `FCME`)이다. 월물이 바뀌면 `manifest.json`의 `code`를 바꾼다. 기록이 남은 뒤에는 폴더를 복사해 새 이름으로 만든다.
- 입력: 일봉 계열 `daily`(직전 거래일까지), 5분봉(`history_bars`로 전날 봉을 20개 이어 받음), 직전 거래일 종가 VIX, 계약당 증거금, 보유분 평가손익.
- 하루는 한국 시간 날짜로 센다. 날짜가 바뀌면 하루 신규 진입 수량을 0으로 되돌리고, 청산해도 되돌리지 않는다.
- 증거금(`margin`) 2083 USD는 NH 모의계좌의 예탁 100,000 USD로 주문 가능한 수량이 48계약인 것에서 추정한 값이다(100,000 ÷ 49 < 증거금 ≤ 100,000 ÷ 48). NH 응답에 계약당 증거금이 따로 없어 `manifest.json`에 적었다.
- 익절·손절 기준(`profit_loss_rate`)은 파라미터로 노출되어 실행 요청에서 바꿀 수 있다.
- 증거금이나 VIX를 알 수 없으면 해당 규칙을 적용하지 못한다. 손익 청산은 건너뛰고, 신규 진입은 `skip`으로 기록한다.
- 판단 기록의 `detail`에는 중기 판단(`mid`: 신호·직전 종가·일봉 이동평균), 장중 판단(`intraday`: 교차·단기선 위치·이동평균·종가), 오늘 진입·보유(`today`: VIX·사용한 진입 수량·한도·보유·증거금 대비 손익)가 남는다. 판단 문구와 주문 사유에는 "중기 매수 허용 · 장중 단기선 상향 교차" 같은 요약이 붙는다.
- 화면 설명(`describe`)은 같은 수치를 중기 판단·장중 판단·오늘 진입·보유 세 구역으로 돌려준다.
