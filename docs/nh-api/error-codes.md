## 읽는 방법

- 오류 코드 또는 오류 메시지로 검색.
- 원본 시트의 순서·번호·코드·메시지·예시를 유지.
- 코드 `0`, 중복 코드, 빈 메시지는 원문 그대로 유지.
- 표의 셀 내부 줄바꿈은 `<br>`로 표시.
- 특수문자와 연속·앞뒤 공백은 필요한 경우 HTML 문자 참조로 표시.
- 빈 셀과 빈 문자열은 표에서 빈칸으로 표시.
- 원문에 없는 코드 의미나 처리 방법은 추가하지 않음.
