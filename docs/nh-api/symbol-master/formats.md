# 종목 마스터 파일 형식

## 확인 범위

- 이 문서의 구조와 샘플 값은 보관된 TXT 8개의 전체 행을 확인한 결과다.
- 모든 파일은 UTF-8 텍스트이며 구분자는 `;`이다.
- 모든 파일은 1행부터 자료가 있으며 별도의 열 이름 행은 없다.
- 열 번호는 1부터 센다.
- 모든 필드 값은 원문 문자열로 읽는다.
- 열의 공식 이름·의미·자료형·단위·코드값 설명·API 대응은 모두 `미확인`이다.
- 날짜·가격·종목코드처럼 보이는 값에도 확인되지 않은 의미를 붙이지 않는다.
- 필드 정의 자료를 확보한 경우에만 근거와 함께 확인 상태를 갱신한다.

## 분리 규칙

- 행 끝의 LF만 제거한 뒤 `;`로 분리.
- 연속된 `;;` 사이의 빈 필드를 유지.
- 마지막 `;` 뒤의 빈 필드를 유지.
- 행이나 필드 전체에 `strip()`을 적용하지 않음.
- 코드 형태의 값과 소수점 형태의 값을 임의로 숫자로 변환하지 않음.
- 같은 열 개수만으로 서로 다른 파일의 필드 의미가 같다고 판단하지 않음.
