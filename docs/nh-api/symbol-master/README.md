## 원본 보관 기준

- 원본 TXT의 하위 폴더명·파일명·파일 바이트를 그대로 보관.
- 원본의 행 순서·공백·빈 필드·선행 0·소수점 표기를 유지.
- 원본 TXT에 열 이름을 추가하거나 값을 변환하지 않음.
- `.DS_Store` 1개는 macOS 폴더 설정 파일이므로 TXT 자료 보관 범위에서 제외.
- 자료 기준일은 확인되지 않았으므로 파일 안의 날짜 형태 값으로 추정하지 않음.

## 검색 방법

저장소 루트에서 실행한다.

```sh
rg --files docs/nh-api/symbol-master/originals
rg -n --max-count 3 --fixed-strings '삼성전자' docs/nh-api/symbol-master/originals
```

두 번째 명령은 파일별로 최대 3개의 일치 행을 출력한다.
다른 문자열을 찾을 때는 검색어만 바꾼다.

### 삼성전자 검색 예시

원본 파일: [국내/국내_주식선물스프레드옵션.txt](originals/국내/국내_주식선물스프레드옵션.txt), 103행.

```text
6;F;1;S11;20261112;day;;STKFBASE;A116B000;A116B000;삼성전자   F 202611 (  10);SEC        F 202611 (  10);234500.00;192200.00;0.00;004;0;10;21;Y;234500.00;192200.00;A116B000;SSELEC611;01;11
```

위 값은 검색한 원문 행의 예시다.
각 값의 의미와 API 입력 필드 대응은 미확인 상태다.
