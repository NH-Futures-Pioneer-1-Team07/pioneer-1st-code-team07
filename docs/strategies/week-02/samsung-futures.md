# 삼성전자 개별주식선물 전략

고저점 돌파가 있을 때 고저 점수와 외국인 수급 점수를 합산해 매매 방향을 결정한다.
합산 점수의 절댓값과 거래량 배수로 목표 보유 계약 수를 조절한다.

## 판단 시점

완성된 일봉과 확정된 외국인 수급으로 신호를 계산한다.
주문은 해당 자료를 사용할 수 있는 다음 거래일에 평가한다.

## 고저 점수

판단 대상 일봉을 제외한 직전 N개 일봉의 최고 고가와 최저 저가를 기준으로 삼는다.
기준 고저점은 일봉마다 슬라이딩 윈도우로 갱신한다.

| 종가 위치 | 고저 점수 B | 동작 |
| --- | --- | --- |
| 기준 고가 초과 | 양수 | 합산 점수로 매매 판단 |
| 기준 저가 미만 | 음수 | 합산 점수로 매매 판단 |
| 기준 고저 사이 또는 경계와 같음 | 0 | 매매 행동 없이 기존 포지션 유지 |

고저 점수의 절댓값은 돌파 거리를 ATR과 돌파 강도 계수로 나눈 뒤 최대 1로 제한한다.
돌파가 없으면 외국인 수급 점수와 관계없이 신규 진입·수량 조정·청산을 하지 않는다.

## 외국인 수급 점수

최근 K개 거래일의 외국인 매수 수량과 매도 수량을 각각 합산한다.

```text
수급 불균형 = (매수 합계 - 매도 합계) / (매수 합계 + 매도 합계)
외국인 수급 점수 F = clip(수급 불균형 / 수급 정규화 계수, -1, 1)
```

외국인 순매수는 양수로 반영한다.
외국인 순매도는 음수로 반영한다.

## 매매 방향

```text
합산 점수 S = 가격 가중치 × B + 수급 가중치 × F
가격 가중치 >= 0, 수급 가중치 >= 0, 두 가중치의 합 = 1
```

돌파가 있을 때 합산 점수가 양수면 매수 방향으로 판단한다.
돌파가 있을 때 합산 점수가 음수면 매도 방향으로 판단한다.
합산 점수가 0이거나 절댓값이 진입 임계값보다 작으면 신규 진입하지 않는다.
고점 돌파 시 매도, 저점 돌파 시 매수도 합산 점수에 따라 허용한다.
반대 포지션으로 전환할 때는 기존 포지션의 청산을 확인한다.

## 목표 계약 수

```text
거래량 배수 = clip(판단 대상 일봉 거래량 / 직전 M개 일봉의 평균 거래량, 0, 배수 상한)
목표 계약 수 = floor(기준 계약 수 × |S| × 거래량 배수)
```

평균 거래량에서 판단 대상 일봉을 제외한다.
목표 계약 수는 손실 예산·증거금·유동성·전략 최대 수량으로 제한한다.
기존 포지션과 유효 미체결 주문을 반영해 목표 수량에 필요한 만큼만 주문한다.

기간·계수·가중치·임계값·기준 계약 수는 검증 후 확정한다.
손절·익절과 돌파 시 중립 신호의 기존 포지션 처리 규칙은 미정이다.
