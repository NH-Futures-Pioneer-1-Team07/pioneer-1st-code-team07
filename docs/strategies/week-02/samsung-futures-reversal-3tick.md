# 삼성전자선물 3틱 역매매 전략

## 1. 범위

확정된 고점·저점을 이탈했다가 회복하는 움직임에 역방향으로 진입한다. 진입 직전 목표까지 최소 목표거리 이상 남은 신호만 사용한다.

## 2. 상품과 입력 자료

삼성전자선물2026년11월물 `A116B000`을 사용한다. 거래승수는10이다. 신호 봉은3분봉이다. 현재 설정의 틱 간격은500원이다.

한국시간 09:00부터 시작하는 당일 완성 봉의 고가·저가·종가와 봉 구간 거래량을 사용한다. 시작·재시작 후에는 전달된 당일 이력 중 마지막 연속 구간만 판단에 사용한다. 봉 누락이 있으면 누락 이전 봉을 지표 계산에서 제외한다.

## 3. 지표와 기준값 정의

한국시간09:00부터 시작하는 당일 완성 봉을 사용한다. 고점·저점은 후보의 앞뒤 각각2봉이 충족돼야 확정된다. 신호 봉 시작 전에 확정된 기준은 신호 봉을 제외한 이력에서 구한다. 거래량 평균은 확인 봉을 제외한 직전10봉으로 계산한다.

## 4. 매수·매도 신호

가장 최근 확정 고점은 가장 최근 확정 저점보다 높아야 한다. 매수 후보는 봉 저가가 기준 저점 이하이고 종가가 기준 저점보다 높은 봉이다. 매도 후보는 봉 고가가 기준 고점 이상이고 종가가 기준 고점보다 낮은 봉이다. 같은 봉에서 양쪽 후보가 생기면 건너뛴다.

바로 다음 연속 봉의 종가가 매수는 기준 저점보다 높고 매도는 기준 고점보다 낮으면 회복을 확인한다. 확인 봉에서는 새 후보를 만들지 않는다. 확인 봉 거래량이 직전10봉 평균의0.5배 이상이어야 한다.

확인 후 다음 가격이 매수는 `손절 < 가격 < 목표`, 매도는 `목표 < 가격 < 손절` 범위에 있어야 한다. 목표까지 방향별 거리가 `최소 목표 틱 × 틱 간격` 이상이어야 한다. 경계인3틱은 허용한다. 신호 확인 직후 첫1분 구간에서 처음 관측한 가격으로 한 번만 검사한다. 그 구간을 놓쳤거나 첫 가격이 조건을 충족하지 않으면 해당 진입을 폐기한다.

## 5. 수량과 보유 방향

한 번에5계약 진입한다. 같은 방향 추가 진입과 청산 후 재진입을 허용한다. 보유 중 반대 방향 후보는 만들지 않는다. 반대 신호로 기존 포지션을 줄이거나 뒤집지 않는다. 총보유량 상한과 일일 손실 한도는 없다.

## 6. 주문 방식

진입과 청산은 시장가다. 진입 주문 유효기간은1봉이다. 유효기간이 지나면 미체결 잔량을 취소하고 해당 진입을 다시 주문하지 않는다. 시장가 주문 전 가격으로 검사한 최소 목표거리가 실제 체결가에도 유지된다고 가정하지 않는다.

## 7. 청산 규칙

매수 손절은 진입 기준 저점보다1,500원 아래이고 목표는 반대쪽 확정 고점이다. 매도 손절은 진입 기준 고점보다1,500원 위이고 목표는 반대쪽 확정 저점이다. 목표와 손절은 진입분마다 관리한다. 가격이 손절 또는 목표에 닿으면 해당 진입분을 시장가 청산한다. 두 조건을 동시에 만족하면 손절을 우선한다.

목표 갱신 방식에서는 새로운 반대쪽 확정 고저점의 가격이 이전 확정값과 달라졌을 때 목표를 갱신한다. 손절은 바꾸지 않는다. 갱신 당시 완성 봉 종가가 이미 새 목표를 지났으면 시장가 청산한다. 목표 고정 방식에서는 최초 목표를 유지한다. 청산 주문 처리 중인 진입분에 중복 청산 주문을 내지 않는다.

## 8. 시각과 날짜 규칙

모든 시각은한국시간이다. 15:24부터 신규·추가 진입을 중단하고 후보와 진입 대기를 폐기한다. 기존 보유분의 손절·익절은 계속 적용한다. 15:30부터 남은 포지션을 전량 시장가 청산한다. 최종거래일을 확인하지 못하면 신규 진입을 하지 않는다. 최종거래일에는 신규 진입을 하지 않고 잔여 포지션 청산을 시도한다.

## 9. 신호를 건너뛰는 조건

확정 고점·저점이 없거나 직전 평균 거래량에 필요한10봉이 없으면 진입하지 않는다. 평균 거래량이0이거나 확인 거래량이 최소 배수보다 작으면 진입하지 않는다. 후보 다음 봉이 연속하지 않으면 확인하지 않는다. 진입 범위·최소 목표거리·시각 조건을 충족하지 않거나 이전 주문이 처리 중이면 진입하지 않는다.

## 10. 파라미터

| 이름 | 기본값 | 의미 |
| --- | --- | --- |
| `bar_minutes` | 3 | 신호 봉의 분 단위, 이 전략에서는3분 고정 |
| `swing_side_bars` | 2 | 고저점 앞뒤 확정 봉 수 |
| `volume_avg_bars` | 10 | 직전 거래량 평균 봉 수 |
| `volume_min_ratio` | 0.5 | 확인 봉 거래량의 최소 평균 배수 |
| `entry_quantity` | 5 | 진입당 계약 수 |
| `stop_offset` | 1500 | 기준 고저점에서 손절까지 원 단위 거리 |
| `min_target_ticks` | 3 | 진입 직전 최소 목표거리 |
| `tick_size` | 500 | 현재 가격대의 원 단위 틱 간격 |
| `order_valid_bars` | 1 | 진입 주문 유효 봉 수 |
| `target_mode` | 갱신 | 갱신 또는 고정 |
| `signal_start_time` | 09:00 | 당일 신호 봉의 시작 시각 |
| `entry_cutoff_time` | 15:24 | 신규·추가 진입 중단 시각 |
| `flatten_time` | 15:30 | 전량 청산 시각 |

## 11. 미정 항목

총보유량 상한과 일일 손실 한도의 추가 여부는 미정이다. 현재 기본값은 제한 없음이다. 신호의 첫 가격 확인 구간은1분이며 다른 값의 파라미터는 제공하지 않는다.
