# ZN 미국 10년 국채선물 이동평균 전략

## 1. 범위

- ZN 미국 10년 국채선물 단독으로 매매한다.
- 직전 거래일 종가와 일봉 이동평균선으로 당일 매매 방향을 허용한다.
- 장중 5분봉 이동평균선 교차로 진입한다.
- 중기 신호가 반대 방향으로 바뀌면 전량 청산한다.

## 2. 기준값

| 항목 | 기준 |
|---|---|
| 매매 상품 | ZN 미국 10년 국채선물 단독 |
| 이동평균 종류 | 종가 기준 단순이동평균(SMA) |
| 중기 이동평균 | 일봉 15일선, 30일선 |
| 장중 봉 단위 | 5분봉 |
| 장중 단기선 | 5분봉 5개 이동평균 |
| 장중 장기선 | 5분봉 20개 이동평균 |
| 전체 보유 한도 | 전날 보유분을 합쳐 30계약 |
| 하루 신규 진입 한도 | VIX와 매매 방향에 따라 1~5계약 |
| 익절·손절 | 전체 보유분의 증거금 대비 합산 손익 ±20% (기본값, UI에서 사용자가 조절) |
| 증거금 | NH선물의 해당 매매 상품 기준 |

## 3. 중기 신호

직전 거래일 종가와 일봉 15일선·30일선으로 판단한다.

| 중기 신호 | 조건 | 허용 방향 |
|---|---|---|
| 매수 | 직전 거래일 종가 > 15일선 > 30일선 | 매수 |
| 매도 | 직전 거래일 종가 < 15일선이고 < 30일선 | 매도 |
| 중립 | 그 외 | 신규 진입 없음 |

## 4. 장중 진입

장중 단기선·장기선은 전일 5분봉에 이어서 계산한다. 장이 열리면 첫 완성 봉부터 신호를 판단한다.

| 방향 | 신호 조건 |
|---|---|
| 매수 | 단기선이 장기선을 상향 교차하고, 해당 봉 종가가 두 선 모두 위 |
| 매도 | 단기선이 장기선을 하향 교차하고, 해당 봉 종가가 두 선 모두 아래 |

- 중기 신호가 허용한 방향의 장중 신호만 진입한다.
- 교차한 봉이 완성된 뒤 다음 봉에서 1계약씩 체결한다.
- 하루 신규 진입 수량은 아래 VIX 한도를 넘지 않는다.
- 보유 수량이 전날 보유분을 합쳐 30계약에 이르면 추가 진입하지 않는다.

### VIX별 하루 신규 진입 한도

VIX는 직전 거래일 종가를 쓴다.

| VIX 구간 | 매수 허용일 | 매도 허용일 |
|---|---|---|
| V < 15 | 1계약 | 5계약 |
| 15 ≤ V < 20 | 2계약 | 4계약 |
| 20 ≤ V < 25 | 3계약 | 3계약 |
| 25 ≤ V < 30 | 4계약 | 2계약 |
| 30 ≤ V | 5계약 | 1계약 |

## 5. 청산과 보유

| 상황 | 동작 |
|---|---|
| 전체 보유분의 증거금 대비 합산 손익이 익절·손절 기준(기본 ±20%)에 도달 | 전량 청산 |
| 중기 신호가 보유 방향과 반대 방향을 허용하는 신호로 바뀜 | 전량 청산 |
| 중기 신호가 중립이거나 장중 역교차가 나옴 | 계속 보유 |

- 청산해도 이미 사용한 하루 신규 진입 한도는 복구하지 않는다.
