# Z3N·ZN 미국 국채선물 스프레드 전략

## 1. 범위

- Z3N 미국 3년 국채선물과 ZN 미국 10년 국채선물의 스프레드를 매매한다.
- [ZF·ZN 스프레드 전략](week04_zf_zn_spread.md)에서 5년물(ZF)을 3년물(Z3N)로 바꾼 전략이다. 진입·청산 규칙과 파라미터는 같고, 종목·계약 비율·승수 처리·데이터 제약이 다르다.
- 최근 일봉 스프레드 분포로 진입·청산 경계(밴드)를 하루에 한 번 계산한다.
- 장중 5분봉 스프레드가 밴드를 벗어나면 평균회귀 방향으로 진입한다.
- 스프레드가 중앙값 근처로 돌아오면 전량 청산한다.
- 손절 기준을 두지 않는다. 청산은 중앙값 복귀 규칙이 맡는다.

## 2. 기준값

| 항목 | 기준 |
|---|---|
| 매매 상품 | `Z3NZ26`(Z3N, 3년물)과 `ZNZ26`(ZN, 10년물). 두 종목 모두 2026년 12월물, 거래소 코드 `FCME` |
| 스프레드 | `2 × Z3N 종가 − 1 × ZN 종가`. 일봉과 5분봉에 같은 식을 쓴다. 가중치 2는 승수 차이(아래)를 반영한 값이다. |
| 보유 한도 | Z3N 1계약과 ZN 1계약을 반대 방향으로 보유하는 한 세트 |
| 운용 종료 | 종료 일시를 지정하지 않는다. 운용 패널에 월물 만기 안내 문구만 보이고, 만기 전 종료는 사람이 직접 한다. 월물 교체와 만기 임박 자동 청산은 하지 않는다. |
| 진입 체결 확인 | 진입 주문 뒤 30초 안에 두 종목이 모두 체결되지 않으면 원상복구한다. 설정값이 아니라 고정값이다. |
| 증거금 | 한 세트 증거금은 `Z3N 증거금 + ZN 증거금`이다(약 2,000·2,063 USD, 합계 약 4,063 USD). Z3N은 주문가능수량(48계약 ↔ 주문가능금액 96,279 USD)으로 역산한 추정치로 1,965~2,006 USD 안이다. 스프레드 할인은 가정하지 않는다. |
| 종목 명세 | 거래승수·슬리피지 1틱의 크기·증거금은 전략 `manifest.json`의 `instruments`에 한 세트 기준으로 둔다. 슬리피지 1틱은 두 종목이 1호가씩 불리하게 체결되는 폭 `2 × 0.00390625 + 1 × 0.015625 = 0.0234375`(한 세트 약 23.4 USD)이다. |

### 거래승수가 다른 종목

Z3N은 1포인트가 2,000 USD, ZN은 1포인트가 1,000 USD다. 스프레드 가격은 승수 1,000 USD 기준으로 맞춰 `2 × Z3N − 1 × ZN`으로 두므로 스프레드 1포인트는 한 세트의 손익 1,000 USD에 대응한다.

| 항목 | 값 |
|---|---|
| 주문 수량(계약 수) | `ratio`: Z3N 1, ZN -1 |
| 스프레드 가격 합성·체결가·수수료 기준가 | `weight`: Z3N 2, ZN -1 (`weight = ratio × 종목 승수 ÷ 1,000`) |
| 금리 민감도(참고) | Z3N 1계약 약 56 USD, ZN 1계약 약 62 USD(추정)라 1:1이 대략 균형이다 |

### 파라미터

사용자가 화면에서 조절하며 최적값을 찾는다.

| 파라미터 | 이름 | 기본값 | 범위 |
|---|---|---|---|
| 일봉 쌍 개수 | `window_days` | 25 (ZF·ZN 전략은 40) | 5 이상. 상한은 두 종목이 공통으로 가진 일봉 이력 길이 |
| 진입 백분위 | `entry_pct` | 0 | 0 이상 50 미만. 0이면 최저값·최고값이 경계 |
| 청산 여유 비율 | `exit_buffer_ratio` | 0.001 | 0 이상 |

## 3. 봉과 밴드 계산

### 봉 짝짓기

| 봉 | 짝짓는 기준 | 사용하는 봉 |
|---|---|---|
| 일봉 | NH 일봉 기준일이 같은 두 종목 | 당일 NH 해외영업일보다 앞선 거래일 중 유효한 쌍 최근 `window_days`개 |
| 5분봉 | NH 해외영업일과 한국시간 봉 시작 시각이 같은 두 종목 | 시작 시각에서 5분이 지나 확정된 봉 |

유효한 쌍은 양쪽 종가가 모두 양의 유한한 수이고 양쪽 거래량이 모두 0보다 큰 쌍이다.

### 밴드

일봉 스프레드 `window_days`개를 정렬해 다음 값을 구한다.

| 값 | 계산 |
|---|---|
| 진입 하단 | 하위 `entry_pct` 분위수 (선형 보간) |
| 진입 상단 | 상위 `entry_pct` 분위수 (선형 보간) |
| 중앙값 | 정렬한 값의 가운데 값. 개수가 짝수이면 가운데 두 값의 평균 |
| 청산 하단 | 중앙값 − `abs(중앙값) × exit_buffer_ratio` |
| 청산 상단 | 중앙값 + `abs(중앙값) × exit_buffer_ratio` |

- 분위수는 정렬한 값 사이를 선형 보간해 구한다.
- `entry_pct`가 0이면 진입 하단은 최저값, 진입 상단은 최고값이다.
- 경계는 해외영업일마다 한 번 계산해 당일 고정한다.
- 다음 해외영업일에는 이월한 포지션에도 새 청산 경계를 적용한다.
- 일봉 쌍이 `window_days`개 미만이면 해당 경계를 쓰는 진입과 청산을 보류한다.
- 신호 비교에는 반올림 전 값을 쓴다.
- 구현은 봉에 해외영업일 정보가 없어 한국 시간 날짜로 해외영업일을 구분한다.

## 4. 진입

장중 밴드 안에 있던 스프레드가 상단을 넘으면 매도하고, 하단 밑으로 내려가면 매수한다.

| 진입 방향 | 현재 5분봉 조건 | 추가 조건 | 시장가 주문 |
|---|---|---|---|
| 스프레드 매도 | 스프레드 > 진입 상단 | 청산 상단 < 진입 상단 | Z3N 1계약 매도, ZN 1계약 매수 |
| 스프레드 매수 | 스프레드 < 진입 하단 | 청산 하단 > 진입 하단 | Z3N 1계약 매수, ZN 1계약 매도 |

- 두 봉은 같은 해외영업일에 속하고 시작 시각 차이가 정확히 5분이어야 한다.
- 직전 봉은 `진입 하단 ≤ 스프레드 ≤ 진입 상단`을 충족해야 한다.
- 전략 보유량과 진행 중인 전략 주문이 모두 없을 때만 봉당 한 번 진입한다.
- 재진입은 청산 완료 뒤에 마감한 두 봉이 위 조건을 충족할 때만 허용한다.
- 계좌 주문 가능 금액이 한 세트 증거금 이상일 때만 진입한다.

### 한쪽만 체결된 경우

- 진입 체결 확인 제한 시간 안에 두 종목이 모두 체결되지 않으면 미체결 주문을 취소한다.
- 체결된 종목은 시장가로 반대 매매해 원상복구한다.
- 원상복구를 마친 뒤에는 청산 완료와 같은 재진입 규칙을 적용한다.

## 5. 청산과 보유

| 보유 방향 | 현재 확정 5분봉의 청산 조건 | 시장가 주문 |
|---|---|---|
| 스프레드 매도 | 스프레드 ≤ 당일 청산 상단 | Z3N 1계약 매수, ZN 1계약 매도 |
| 스프레드 매수 | 스프레드 ≥ 당일 청산 하단 | Z3N 1계약 매도, ZN 1계약 매수 |

- 청산은 현재 확정 봉 하나로 판단한다.
- 청산 조건이 없고 운용을 종료하기 전이면 보유를 이어가며 다음 해외영업일로 이월할 수 있다.
- 손익 기준 청산은 없다. 스프레드가 돌아오지 않으면 사람이 운용을 종료할 때까지 보유한다.

## 6. 구현 시 확인

### 확인한 것 (모의환경, 2026-11-11)

| 항목 | 결과 |
|---|---|
| 종목 | `Z3NZ26`은 종목 마스터에 있고 현재가는 조회된다. 호가 단위 0.00390625, 틱 가치 7.8125 USD라 승수는 2,000이다. |
| 일봉 | **`Z3NZ26`은 일봉이 0개다**(`ZNZ26`은 167개). 그래서 이 전략은 두 종목 모두 5분봉으로 합성한 일봉을 쓴다(아래). |
| 5분봉 | 두 종목 짝 기준 백테스트 가능 기간은 2026-08-18~11-10이지만 `Z3NZ26`은 봉이 듬성한 날이 17일 있다(최근 하루 83~235개, 정상 276개, 2026-11-11에는 1개). 하루 거래량도 수천 계약으로 `ZNZ26`(수백만)보다 훨씬 적다. |
| 백테스트 동작 | 기본값으로 2026-10-01~10-20을 돌리면 오류 없이 거래 0건으로 끝난다(일봉이 없어 판단 보류). |
| 증거금 | `ZNZ26` 1계약 예약 증거금은 2,063 USD다. `Z3NZ26`은 주문가능수량으로 역산한 추정(1,965~2,006 USD)이다. |

### 일봉 합성

- NH 일봉이 한 종목이라도 비어 있으면 **두 종목 모두** 5분봉으로 일봉을 합성한다. NH 일봉은 정산가 기준이라 합성한 일봉(마지막 체결가)과 섞으면 스프레드가 어긋나기 때문이다.
- 영업일은 한국 시간에서 7시간을 뺀 날짜다(CME 정규 휴장 직전·직후를 가른다). 시가는 첫 5분봉 시가, 종가는 마지막 5분봉 종가, 고가·저가는 최댓값·최솟값, 거래량은 합이다.
- `ZNZ26`으로 확인했다. 합성 일봉의 거래량이 NH 일봉과 거의 같다(차이 0.01% 안팎)라 영업일 경계가 맞다. 종가는 NH 정산가와 0.02~0.34 차이가 난다.
- 5분봉 이력이 2026-08-18부터라 일봉 쌍이 61개(2026-08-18~11-10)뿐이다. `window_days`를 40 이하로 둔다. 40이어도 백테스트 초반에는 쌍이 모자라 판단을 보류한다.
- 실제 데이터로 2026-10-14~11-10을 돌려 `window_days` 5·10·20·30은 거래 18·14·4·2건, 40은 0건이었다(파라미터를 고르는 근거로 쓰지 않는다).

### 한계와 남은 것

| 항목 | 내용 |
|---|---|
| 판단 보류 | 일봉 쌍이 `window_days`개 미만이면 진입과 청산을 보류하고 `skip`으로 기록한다. |
| 데이터 | `Z3NZ26`은 5분봉이 듬성하고 거래량이 적다(하루 수천 계약). 진입 시장가 체결과 두 종목이 같은 시각에 5분봉을 가졌는지에 따라 판단 기회가 줄 수 있다. |
| 합성 일봉 | 정산가가 아닌 마지막 체결가라 ZF·ZN 전략의 일봉 스프레드와 값이 조금 다르다. |
| 증거금 | `Z3NZ26` 증거금은 실제 주문으로 예약 증거금을 확인해 값을 고친다. |
| 해외 모의 주문 | ZF·ZN 전략 문서의 "해외 모의 주문" 항목과 같다. 체결·취소는 한국시간 낮에 확인한다. |
