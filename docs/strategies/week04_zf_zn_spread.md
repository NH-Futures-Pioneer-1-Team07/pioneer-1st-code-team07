# ZF·ZN 미국 국채선물 스프레드 전략

## 1. 범위

- ZF 미국 5년 국채선물과 ZN 미국 10년 국채선물의 스프레드를 매매한다.
- 최근 일봉 스프레드 분포로 진입·청산 경계(밴드)를 하루에 한 번 계산한다.
- 장중 5분봉 스프레드가 밴드를 벗어나면 평균회귀 방향으로 진입한다.
- 스프레드가 중앙값 근처로 돌아오면 전량 청산한다.
- 손절 기준을 두지 않는다. 청산은 중앙값 복귀 규칙이 맡는다.

## 2. 기준값

| 항목 | 기준 |
|---|---|
| 매매 상품 | `ZFZ26`(ZF, 5년물)과 `ZNZ26`(ZN, 10년물). 두 종목 모두 2026년 12월물, 거래소 코드 `FCME` |
| 스프레드 | `3 × ZF 종가 − 2 × ZN 종가`. 일봉과 5분봉에 같은 식을 쓴다. |
| 보유 한도 | ZF 3계약과 ZN 2계약을 반대 방향으로 보유하는 한 세트 |
| 필수 운용 설정 | 두 종목 모두 주문할 수 있는 종료 일시(한국시간), 진입 체결 확인 제한 시간(양의 정수 초) |
| 종료 일시 지정 | 12월물 최초 통지일 이전으로 지정한다. 월물 교체와 만기 임박 자동 청산은 하지 않는다. |
| 증거금 | 한 세트 증거금은 `3 × ZF 증거금 + 2 × ZN 증거금`이다(1,375·2,063 USD, 합계 8,251 USD). 스프레드 할인은 가정하지 않는다. |
| 종목 명세 | 거래승수·슬리피지 1틱의 크기·증거금은 전략 `manifest.json`의 `instruments`에 한 세트 기준으로 둔다. 슬리피지 1틱은 두 종목이 1호가씩 불리하게 체결되는 폭 `3 × 0.0078125 + 2 × 0.015625 = 0.0546875`이다. |

두 종목의 거래승수가 같아서 스프레드 1포인트가 한 세트의 손익 1포인트에 대응한다.

### 파라미터

사용자가 화면에서 조절하며 최적값을 찾는다.

| 파라미터 | 이름 | 기본값 | 범위 |
|---|---|---|---|
| 일봉 쌍 개수 | `window_days` | 40 | 5 이상. 상한은 두 종목이 공통으로 가진 일봉 이력 길이 |
| 진입 백분위 | `entry_pct` | 0 | 0 이상 50 미만. 0이면 최저값·최고값이 경계 |
| 청산 여유 비율 | `exit_buffer_ratio` | 0.001 | 0 이상 |

## 3. 봉과 밴드 계산

### 봉 짝짓기

| 봉 | 짝짓는 기준 | 사용하는 봉 |
|---|---|---|
| 일봉 | NH 일봉 기준일이 같은 두 종목 | 당일 NH 해외영업일보다 앞선 거래일 중 유효한 쌍 최근 `window_days`개 |
| 5분봉 | NH 해외영업일과 한국시간 봉 시작 시각이 같은 두 종목 | 시작 시각에서 5분이 지나 확정된 봉 |

유효한 쌍은 양쪽 종가가 모두 양의 유한한 수이고 양쪽 거래량이 모두 0보다 큰 쌍이다.

### 밴드

일봉 스프레드 `window_days`개를 정렬해 다음 값을 구한다.

| 값 | 계산 |
|---|---|
| 진입 하단 | 하위 `entry_pct` 분위수 (선형 보간) |
| 진입 상단 | 상위 `entry_pct` 분위수 (선형 보간) |
| 중앙값 | 정렬한 값의 가운데 값. 개수가 짝수이면 가운데 두 값의 평균 |
| 청산 하단 | 중앙값 − `abs(중앙값) × exit_buffer_ratio` |
| 청산 상단 | 중앙값 + `abs(중앙값) × exit_buffer_ratio` |

- 분위수는 정렬한 값 사이를 선형 보간해 구한다.
- `entry_pct`가 0이면 진입 하단은 최저값, 진입 상단은 최고값이다.
- 경계는 해외영업일마다 한 번 계산해 당일 고정한다.
- 다음 해외영업일에는 이월한 포지션에도 새 청산 경계를 적용한다.
- 일봉 쌍이 `window_days`개 미만이면 해당 경계를 쓰는 진입과 청산을 보류한다.
- 신호 비교에는 반올림 전 값을 쓴다.
- 구현은 봉에 해외영업일 정보가 없어 한국 시간 날짜로 해외영업일을 구분한다.

## 4. 진입

장중 밴드 안에 있던 스프레드가 상단을 넘으면 매도하고, 하단 밑으로 내려가면 매수한다.

| 진입 방향 | 현재 5분봉 조건 | 추가 조건 | 시장가 주문 |
|---|---|---|---|
| 스프레드 매도 | 스프레드 > 진입 상단 | 청산 상단 < 진입 상단 | ZF 3계약 매도, ZN 2계약 매수 |
| 스프레드 매수 | 스프레드 < 진입 하단 | 청산 하단 > 진입 하단 | ZF 3계약 매수, ZN 2계약 매도 |

- 두 봉은 같은 해외영업일에 속하고 시작 시각 차이가 정확히 5분이어야 한다.
- 직전 봉은 `진입 하단 ≤ 스프레드 ≤ 진입 상단`을 충족해야 한다.
- 전략 보유량과 진행 중인 전략 주문이 모두 없을 때만 봉당 한 번 진입한다.
- 재진입은 청산 완료 뒤에 마감한 두 봉이 위 조건을 충족할 때만 허용한다.
- 계좌 주문 가능 금액이 한 세트 증거금 이상일 때만 진입한다.

### 한쪽만 체결된 경우

- 진입 체결 확인 제한 시간 안에 두 종목이 모두 체결되지 않으면 미체결 주문을 취소한다.
- 체결된 종목은 시장가로 반대 매매해 원상복구한다.
- 원상복구를 마친 뒤에는 청산 완료와 같은 재진입 규칙을 적용한다.

## 5. 청산과 보유

| 보유 방향 | 현재 확정 5분봉의 청산 조건 | 시장가 주문 |
|---|---|---|
| 스프레드 매도 | 스프레드 ≤ 당일 청산 상단 | ZF 3계약 매수, ZN 2계약 매도 |
| 스프레드 매수 | 스프레드 ≥ 당일 청산 하단 | ZF 3계약 매도, ZN 2계약 매수 |

- 청산은 현재 확정 봉 하나로 판단한다.
- 청산 조건이 없고 운용 종료 전이면 보유를 이어가며 다음 해외영업일로 이월할 수 있다.
- 손익 기준 청산은 없다. 스프레드가 돌아오지 않으면 운용 종료 일시까지 보유한다.

## 6. 구현 시 확인

### 확인한 것 (모의환경, 2026-11-11)

| 항목 | 결과 |
|---|---|
| 일봉 | 두 종목 모두 2026-11-10까지 받는다. 유효한 쌍은 126개(2026-05-05~11-10)이므로 `window_days`의 상한은 이력 길이에 묶인다. |
| 5분봉 | `ZFZ26`은 2026-05-06부터, `ZNZ26`은 2026-03-30부터다. 두 종목 모두 2026-08-20부터 온전하므로 5분봉 백테스트는 이 날 이후로 시작한다. |
| 증거금 | 1계약 예약 증거금이 `ZFZ26` 1,375 USD, `ZNZ26` 2,063 USD다. 한 세트는 `3 × 1,375 + 2 × 2,063 = 8,251` USD다. |
