# 코스피200 베이시스 z-score 전략

## 1. 범위

- 코스피200 선물 1개 월물만 매매한다.
- 베이시스는 `선물 가격 − 코스피200 지수`이다.
- 최근 5분봉 베이시스의 z-score가 진입 기준을 벗어나면 평균회귀 방향으로 1계약을 진입한다.
- 증거금 대비 수익률이 설정값에 닿으면 이익이든 손실이든 청산한다.
- 현물 지수는 거래하지 않고 베이시스 계산에만 쓴다.

## 2. 기준값

| 항목 | 기준 |
|---|---|
| 매매 상품 | 코스피200 선물 2026년 12월물 `A016C000`. 거래승수 250,000원, 틱 0.05, 틱가치 12,500원 |
| 현물 지수 | 코스피200 지수 `KRD020020016`. 현재가 API의 `spt_sym` 값이다. |
| 최종거래일 | 2026-12-10 |
| 거래 수량 | 매매마다 1계약. 보유 한도도 1계약이다. |
| 신호 봉 | 5분봉. 주간장만 쓴다. |
| 신호 시간 | 한국시간 09:00 이후 봉부터 15:20 전 봉까지 |
| 주문 방식 | 시장가 |
| 증거금 | 계약당 개시증거금. 진입할 때 `품목별세부정보` API의 `계약당개시증거금액`을 읽어 그 포지션에 고정한다. (2026-11-18 조회값 40,463,850원, 비율 21%) |

## 3. 베이시스와 z-score

### 베이시스 봉

| 항목 | 기준 |
|---|---|
| 짝짓기 | 기준일과 봉 시각이 같은 선물 5분봉과 지수 5분봉 |
| 봉 베이시스 | `선물 종가 − 지수 종가` |
| 유효한 봉 | 두 종가가 모두 양의 유한한 수인 짝 |
| 제외 | 한쪽에만 있는 봉 |

- 5분봉은 확정된 봉만 쓴다.
- 신호 봉 시간 밖의 봉은 z-score 계산 이력에도 쓰지 않는다.
- 전일 봉도 이력에 포함한다. 같은 월물만 쓰므로 월물 교체에 따른 수준 변화는 없다.
- 봉 시각이 봉의 시작인지 마감인지는 구현에서 확인해 두 종목에 같은 기준을 쓴다.

### z-score

| 값 | 계산 |
|---|---|
| 평균 | 현재 봉 직전 `window_bars`개 유효 봉 베이시스의 평균 |
| 표준편차 | 같은 `window_bars`개의 모표준편차 |
| z-score | `(현재 봉 베이시스 − 평균) ÷ 표준편차` |

- 현재 봉은 평균과 표준편차에 포함하지 않는다.
- 이력이 `window_bars`개 미만이면 신호를 판단하지 않는다.
- 표준편차가 0이면 신호를 판단하지 않는다.
- 신호 비교에는 반올림 전 값을 쓴다.

## 4. 진입

베이시스가 평균보다 크게 벌어지면 선물이 비싸다고 보고 매도한다. 평균보다 크게 낮아지면 선물이 싸다고 보고 매수한다.

| 진입 방향 | 현재 봉 조건 | 시장가 주문 |
|---|---|---|
| 선물 매도 | z-score ≥ `entry_z` | 선물 1계약 매도 |
| 선물 매수 | z-score ≤ −`entry_z` | 선물 1계약 매수 |

- 직전 봉이 같은 날 연속 봉이고 직전 봉의 `|z-score| < entry_z`일 때만 진입한다. 기준을 넘은 상태가 이어지는 동안 반복 진입하지 않는다.
- 보유 포지션과 진행 중인 전략 주문이 모두 없을 때만 진입한다.
- 청산 뒤에는 새로 마감한 두 봉이 위 조건을 충족할 때만 다시 진입한다.
- 최종거래일에는 신규 진입을 하지 않는다. 최종거래일을 확인하지 못해도 신규 진입을 하지 않는다.
- 계좌 주문 가능 금액이 계약당 개시증거금 이상일 때만 진입한다.

## 5. 청산과 보유

증거금 대비 수익률은 다음과 같이 계산한다.

| 값 | 계산 |
|---|---|
| 평가손익 | 매수: `(현재 봉 선물 종가 − 진입가) × 250,000`, 매도: `(진입가 − 현재 봉 선물 종가) × 250,000` |
| 증거금 대비 수익률 | `평가손익 ÷ 진입 시 계약당 개시증거금 × 100` |

| 조건 | 시장가 주문 |
|---|---|
| 수익률 ≥ +`exit_return_pct` (이익 청산) | 보유 방향의 반대 매매로 전량 청산 |
| 수익률 ≤ −`exit_return_pct` (손절) | 보유 방향의 반대 매매로 전량 청산 |

- 이익 청산과 손절은 같은 설정값 하나를 쓴다. 10%로 정하면 +10%와 −10%에서 청산한다.
- 청산은 확정된 5분봉 종가 하나로 판단한다.
- z-score가 평균으로 돌아와도 청산하지 않는다.
- 청산 조건이 없으면 보유를 이어가며 다음 거래일로 이월할 수 있다.
- 월물 만기 전 종료와 월물 교체는 하지 않는다. 최종거래일 전 종료는 사람이 직접 한다.
- 수수료와 슬리피지는 평가손익에 넣지 않는다. 손익 집계에는 백테스트의 수수료·슬리피지 가정을 따른다.

## 6. 파라미터

사용자가 화면에서 조절하며 최적값을 찾는다.

| 파라미터 | 이름 | 기본값 | 범위 |
|---|---|---|---|
| z-score 계산 5분봉 개수 | `window_bars` | 60 | 10 이상 |
| 진입 z-score 기준 | `entry_z` | 2.0 | 0 초과 |
| 청산 수익률 기준(%) | `exit_return_pct` | 10 | 0 초과 |

- 기본값은 출발점이며 검증으로 정한 값이 아니다.
- 거래 수량 1계약은 파라미터가 아니라 고정값이다.

## 7. 신호를 건너뛰는 조건

- 직전 `window_bars`개 유효 봉이 없으면 건너뛴다.
- 표준편차가 0이면 건너뛴다.
- 직전 봉이 같은 날 연속 봉이 아니면 건너뛴다.
- 직전 봉이 이미 기준을 넘었으면 건너뛴다.
- 보유 중이거나 이전 주문이 처리 중이면 건너뛴다.
- 신호 봉 시간 밖이면 건너뛴다.
- 최종거래일이면 건너뛴다.
- 주문 가능 금액이 부족하면 건너뛴다.
- 건너뛸 때 사유를 남긴다.

## 8. 구현 시 확인

### 확인한 것 (모의환경, 2026-11-18)

| 항목 | 결과 |
|---|---|
| 베이시스 API | 국내_현재가의 `fact_bas`(실제베이시스)가 `last_pric − spt_pric`과 같다. 선물 767.20, 지수 770.74일 때 −3.54였다. `theo_bas`(이론베이시스)와 `dev`(괴리도)도 있다. |
| 5분봉 베이시스 | `fact_bas`는 현재가 시점 값만 주고 이력이 없다. 국내_차트(분)에 선물 코드 `A016C000`과 지수 코드 `KRD020020016`을 넣으면 둘 다 5분봉이 온다. 두 종가의 차이가 봉 베이시스다. |
| 봉 시각 | 선물은 08:45~15:45(주간), 지수는 08:50~15:30이다. 지수에는 20:05 봉도 하나 있다. 짝이 있는 봉만 쓰므로 영향이 없다. |
| 증거금 | `품목별세부정보`의 코스피200선물 개시증거금 21%, 계약당 40,463,850원 |

### 남은 것

| 항목 | 내용 |
|---|---|
| 봉 시각 의미 | 5분봉 `exch_tm`이 시작인지 마감인지 확인한다. |
| 지수 봉 이력 길이 | 지수 5분봉을 얼마나 과거까지 받을 수 있는지 확인한다. 백테스트 가능 기간이 여기에 묶인다. |
| 장 마감 구간 | 지수는 15:30에 끝나고 선물은 15:45까지 거래한다. 신호 봉 시간을 15:20 전으로 제한한 것이 적절한지 백테스트로 확인한다. |
| 만기 접근 | 만기에 가까워지면 베이시스가 0으로 수렴한다. z-score 이력의 평균이 이 영향을 받는지 확인한다. |
| 실시간 | 실시간 체결(`KA`)에도 `mkt_bas`(마켓베이시스)와 `und_last_pric`(기초자산현재가)가 있다. 이 전략은 백테스트와 같은 5분봉 계산을 쓰므로 5분봉 종료 시점의 차트 조회로 판단한다. |
