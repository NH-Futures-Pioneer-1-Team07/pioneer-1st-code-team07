# 모의매매 및 백테스트 프로그램 요구사항

## 프로그램 개요

- 만들어 둔 매매 전략을 선택해 NH선물 모의계좌로 운용한다.
- 같은 전략을 과거 데이터로 백테스트할 수 있다.
- 사용 환경은 데스크톱 웹 UI다.
- 공통 메뉴에서 모의매매 페이지와 백테스트 페이지를 오간다.

## 모의매매 페이지

### 전략 선택

- 지금까지 만든 매매 전략을 하나의 목록으로 제공한다.
- 전략은 이 페이지 안의 카드 목록에서 고른다.
- 각 카드에 전략 이름을 표시하고, 선택한 카드에는 설명을 펼쳐 표시한다.
- 전략이 많아도 목록 높이는 고정하고 목록 안에서 스크롤한다.
- 화면에서 선택한 전략과 실제 운용 중인 전략을 구분해 표시한다.
- 모의매매는 한 번에 전략 1개와 종목 1개를 운용한다.

### 종목과 시세

- 운용 종목은 선택한 전략이 지원하는 첫 번째 종목으로 정하고, 별도의 종목 검색·선택은 제공하지 않는다.
- 운용 종목의 종목명·종목코드·월물·만기를 표시한다.
- 웹소켓으로 운용 종목의 실시간 시세를 수신한다.
- 현재가·등락·거래량·호가와 가격 차트를 표시한다.
- 시세 수신 시각과 연결 상태를 표시한다.

### 계좌와 성과

- NH 모의계좌를 조회해 예탁현금·예탁자산·주문 가능 금액·증거금을 표시한다.
- 각 금액 카드에는 그 숫자가 무엇을 뜻하는지 한 줄로 설명하는 글을 함께 표시한다.
- 운용 중에도 NH 모의계좌를 조회해 계좌 정보의 표시값을 갱신한다.
- 계좌의 미체결 주문과 보유 포지션을 표시한다.
- 보유 포지션과 미체결 주문은 탭으로 나누지 않고, 화면을 좌우 절반씩 나눠 함께 표시한다.
- 보유 포지션에는 종목·매매구분(매수/매도)·계약 수·평균 진입가·현재가·평가손익을 표시한다.
- 종목은 월물까지 붙인 이름(예: 삼성전자 선물 · 2026.12)으로 표시한다. 월물이 다르면 다른 종목이다.
- 보유 포지션·미체결 주문·이력 목록·이력 상세·백테스트 화면 등 종목이 나오는 모든 곳에서 같은 형식(이름 · 월물)으로 표시한다.
- 현재 운용의 실현손익·평가손익·비용을 표시한다.
- 계좌 전체의 자산과 현재 운용의 손익을 구분해 표시한다.

### 운용 시작과 종료

- 사용자가 운용 시작 버튼을 누르면 NH 모의계좌의 현재 정보를 조회한다.
- 선택한 전략과 종목으로 새 운용을 시작한다.
- 운용 중인 전략의 판단 시점과 주문 조건에 따라 NH 모의계좌에 주문을 전송한다.
- 주문 수량은 주문 시 조회한 계좌의 주문 가능 금액·수량과 전략의 수량 한도 안에서 결정한다.
- 화면에는 운용 중인 전략 이름·종목·운용 상태를 표시한다.

정상 운용 종료는 다음 순서로 처리한다.

1. 종료할 운용의 신규 주문 판단을 중단한다.
2. 종료할 운용에서 낸 미체결 주문을 취소한다.
3. 종료할 운용의 보유 포지션을 청산한다.
4. 해당 운용의 미체결 주문과 보유 수량이 모두 0이면 종료한다.

### 계좌 전체 정리

모의매매 화면에 `미체결 취소·전체 포지션 청산` 버튼을 항상 제공한다.
사용자가 버튼을 누르면 다음 순서로 처리한다.

1. 운용 중인 전략의 신규 주문 판단을 중단한다.
2. 계좌 전체의 미체결 주문을 취소한다.
3. 취소 처리 중 체결된 수량을 반영해 계좌 전체의 남은 포지션을 청산한다.
4. 정리 결과를 조회한 미체결 주문과 보유 수량으로 표시한다.

### 모의매매 이력

- 모의매매 이력에서 매매 판단과 체결 내역을 함께 확인한다.
- NH 모의계좌의 주문·체결 내역은 NH 응답을 기준으로 표시한다.
- 모의매매 중 전략이 점수를 계산할 때마다 계산 시각·점수·매매 여부를 이력에 추가해 표시한다.
- 점수 항목과 계산 시점은 전략마다 다를 수 있다.
- 매매 여부는 매수·매도·진입 보류 등 해당 전략의 판단 결과로 표시한다.

| 내역 | 표시할 내용 |
| --- | --- |
| 매매 판단 | 계산 시각, 판단 결과(매수·매도·진입 보류), 판단에 따른 주문의 가격·수량, 계산된 점수 |
| 체결 | 체결 시각, 매매구분(매수/매도), 체결 수량, 체결 가격, 전략 주문 당시 점수 |

- 별도의 주문 내역 탭은 두지 않고, 주문 정보는 매매 판단의 가격·수량과 체결로 확인한다.
- 부분체결은 건별 체결로 표시한다.
- 전략에 따라 낸 주문은 체결 내역에 주문 당시 계산된 점수를 함께 표시한다.
- 매매하지 않은 시점의 점수와 매매 여부도 이력에 기록한다.
- 매매 판단에 따라 주문이 발생하면 해당 주문과 체결 내역을 이력에서 확인한다.
- 전략 판단에 따라 낸 주문에는 판단 당시의 전략 이름·지표·점수·매매 판단을 보존한다.

- 모의매매 이력 목록에는 전략·종목·운용 시작 및 종료 시각·손익을 표시한다.
- 이력을 선택하면 해당 운용의 전략 이름과 매매 판단·체결 기록을 조회한다.
- 모의매매 이력은 행의 아무 곳이나 선택해 상세를 연다.
- 모의매매 이력과 상세에는 운용 번호를 표시하지 않는다. 운용은 전략·시작·종료 시각으로 구분한다.
- 상세를 열면 모의매매 이력이 왼쪽 절반으로 줄어들고, 오른쪽 절반에 운용 상세를 표시한다.
- 상세를 닫으면 모의매매 이력이 다시 전체 폭으로 돌아간다.
- 화면이 절반으로 나뉜 동안 모의매매 이력에는 전략·시작·종료·순손익만 표시한다.
- 프로그램을 다시 시작한 뒤에도 이전 모의매매 이력과 상세 기록을 조회한다.

## 백테스트 페이지

### 전략과 테스트 조건 선택

- 지금까지 만든 매매 전략을 하나의 목록으로 제공한다.
- 전략은 이 페이지 안의 카드 목록에서 고른다.
- 각 카드에 전략 이름을 표시하고, 선택한 카드에는 설명을 펼쳐 표시한다.
- 전략이 많아도 목록 높이는 고정하고 목록 안에서 스크롤한다.
- 테스트 종목은 선택한 전략이 지원하는 첫 번째 종목으로 정하고, 종목명·종목코드·월물·만기를 표시한다.
- 시작일과 종료일은 하나의 달력에서 선택한다.
- 달력은 시작일·종료일을 동그란 표시로, 그 사이 날짜를 연한 색의 띠로 이어서 표시한다.
- 선택할 수 없는 날짜는 비활성으로 표시한다.
- 달력은 평소에 시작일·종료일 요약만 보이도록 접어 두고, 요약을 누르면 아래 내용을 밀지 않고 위에 떠 있는 달력으로 연다.
- 종료일 선택이 끝나거나 바깥을 누르거나 Escape를 누르면 달력을 닫는다.
- 초기자금을 입력한다.
- 테스트 기간은 테스트 종목의 개별 월물 기간 안에서 정한다.
- 백테스트를 시작하기 전에 수수료를 표시한다.
- 슬리피지·주문 및 체결 시점·체결 가격 기준은 시작 전 화면에 표시하지 않는다.
- 사용자가 선택한 기간과 과거 데이터로 테스트할 수 있는 기간을 표시한다.

### 백테스트 실행

- 선택한 전략의 점수를 계산하는 데 필요한 테스트 시작일 이전 데이터를 준비한다.
- 각 시점의 판단에는 그 시점에 사용할 수 있었던 과거 데이터만 사용한다.
- 선택한 기간의 백테스트를 일괄 계산한다.
- 과거 데이터 준비와 백테스트 계산의 진행 상황을 표시한다.
- 진행 표시는 백테스트 실행 전에도 같은 자리에 두고, 실행 전 상태와 현재 선택한 조건을 보여준다.
- 백테스트가 끝나면 진행 표시를 없애지 않고 완료 표시로 바꿔 남긴다.
- 완료 표시는 다음 백테스트를 시작할 때까지 유지한다.
- 백테스트에는 미리 정한 비용과 체결 가정을 적용한다.
- 백테스트의 주문과 체결은 입력한 초기자금과 정해진 체결 가정으로 계산한다.

- 백테스트 기간이 끝나면 백테스트에서 보유 중인 포지션을 청산한다.
- 백테스트 기간 종료에 따른 청산은 `백테스트 종료 청산`으로 기록한다.
- 해당 청산의 가격과 비용을 백테스트 결과에 반영한다.

### 백테스트 결과와 이력

| 결과 | 표시할 내용 |
| --- | --- |
| 성과 | 초기자금, 최종자산, 순손익 |
| 매매 판단 | 계산 시각, 판단 결과(매수·매도·진입 보류), 판단에 따른 주문의 가격·수량, 계산된 점수 |
| 체결 | 체결 시각, 매매구분(매수/매도), 체결 수량, 체결 가격, 수수료, 전략 주문 당시 점수 |

- 각 시점에 계산한 점수와 매매 여부를 백테스트 이력에 기록한다.
- 매매하지 않은 시점의 점수와 매매 여부도 이력에 기록한다.
- 별도의 주문 탭은 두지 않고, 주문 정보는 매매 판단의 가격·수량과 체결로 확인한다.
- 매매 판단과 체결의 표시 방식은 모의매매 이력과 같게 한다.
- 전략에 따라 낸 주문은 체결 내역에 주문 당시 계산된 점수를 함께 표시한다.

- 백테스트 이력 목록에는 실행 일시·전략·종목·테스트 대상 시작일과 종료일·초기자금·손익을 표시한다.
- 백테스트 실행은 별도 이름이나 번호 없이 실행한 일시로 구분한다.
- 이력을 선택하면 해당 테스트의 전략 이름과 매매 판단·체결 기록을 조회한다.
- 백테스트 이력은 행의 아무 곳이나 선택해 상세를 연다.
- 상세를 열면 실행 이력이 왼쪽 절반으로 줄어들고, 오른쪽 절반에 실행 상세 기록을 표시한다.
- 상세를 닫으면 실행 이력이 다시 전체 폭으로 돌아간다.
- 화면이 절반으로 나뉜 동안 실행 이력에는 실행·전략·테스트 기간·순손익만 표시한다.
- 이력 상세에는 적용한 비용(수수료·슬리피지)과 샘플 수량·승수를 표시한다.
- 백테스트 결과와 실행 조건은 이후에 다시 조회할 수 있도록 보존한다.
- 프로그램을 다시 시작한 뒤에도 이전 백테스트 이력과 상세 기록을 조회한다.

## 공통 및 기타 요구사항

### 화면과 디자인

- 디자인은 `/Users/yong/study/aiTrade/design`을 참조한다.
- 다크 배경과 중립색 표면을 사용한다.
- 주요 행동과 선택 상태에 NH선물 웹 로고에서 추출한 골든 옐로(`#FFB819`, RGB 255·184·25)를 사용한다.
- 색상 출처는 [NH선물 공식 홈페이지 로고 이미지](https://www.futures.co.kr/images/common/logo.png)다.
- 글꼴은 Pretendard를 사용한다.
- 카드·표·상세 영역은 참조 디자인의 명도와 간격을 활용한다.
- 데스크톱은 오른쪽에 고정된 52px 아이콘 메뉴바를 사용한다.
- 전략은 별도 패널 없이 각 페이지 안에서 선택한다.
- 모의매매와 백테스트는 각 페이지의 전략을 따로 선택하고 서로 영향을 주지 않는다.
- 모의매매 화면은 백테스트와 같이 조작 영역을 왼쪽에 둔다. 왼쪽에 전략 운용, 가운데에 시세·차트, 오른쪽에 호가를 배치한다.
- 표·목록 영역은 높이를 고정하고(기본 220px), 내용이 늘어나면 영역 안에서 스크롤한다.
- 스크롤할 때 표의 제목 줄은 위에 고정한다.
- 모든 표와 타임라인의 행 높이는 44px로 같게 한다.
- 매수/매도 구분 컬럼의 이름은 NH선물 API 용어에 맞춰 "매매구분"으로 쓴다.
- 표와 타임라인의 시각은 년월일까지 포함해 표시한다(예: 2026.10.27 09:15:00).
- 한 행은 한 줄로 표시하고, 보조 정보는 같은 줄에 작은 글씨로 붙인다.
- 이력 목록과 상세가 좌우로 나뉜 동안에는 두 패널의 아래 끝을 맞춘다.
- 데스크톱 화면만 개발한다.
- 모바일·태블릿 등 좁은 화면의 레이아웃은 개발 범위에서 제외한다.

### 전략 판단

- 모의매매 또는 백테스트를 시작할 때 선택한 전략의 판단 규칙을 적용한다.
- 같은 전략을 선택한 모의매매와 백테스트에는 동일한 판단 규칙을 적용한다.

### 프로그램 실행

| 프로그램·계좌 상태 | 동작 |
| --- | --- |
| 매매 실행 프로그램 시작 | 초기 화면에서 시작한다. |
| 계좌에 기존 주문·포지션이 있는 상태 | 기존 주문·포지션이 있어도 새 운용을 시작할 수 있다. |
| 브라우저 종료 | 매매 실행 프로그램이 켜져 있으면 진행 중인 운용을 계속한다. |
| 백테스트 페이지로 이동 | 진행 중인 모의매매를 계속한다. |
| 매매 실행 프로그램 강제 종료 | 다음 시작 시 NH 모의계좌를 조회해 남은 주문·포지션을 표시한다. |
