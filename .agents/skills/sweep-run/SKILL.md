# 조합 탐색 실행

전략의 파라미터·기간 조합을 백테스트하고 결과를 `backend/sweeps/<전략 id>/`에 쌓는다. 보고서 작성은 `sweep-report` 스킬이 맡는다.

계산과 저장은 `python -m app.sweep`이 한다. 직접 백테스트를 흉내 내거나 결과 파일을 고치지 않는다.

## 절차

모든 명령은 `backend/`에서 실행한다.

1. **전략을 이해한다.**
   - `docs/strategies/<전략 id>.md`와 `backend/strategies/<전략 id>/manifest.json`의 `parameters`를 읽는다.
   - 파라미터의 기본값, 의미, `min`/`max`를 확인한다. 범위를 벗어난 값은 실행 전에 거절된다.
2. **가능 기간을 확인한다.**
   - `uv run python -m app.sweep range <전략 id>`를 실행한다(NH 모의 API를 호출한다).
   - `sparse_days`(봉이 적은 날)가 많은 앞쪽 구간은 피하고, 온전한 구간만 기간으로 쓴다. 종료일은 오늘보다 이전이어야 한다.
3. **이미 해 본 것을 확인한다.**
   - `backend/sweeps/<전략 id>/results.jsonl`이 있으면 `uv run python -m app.sweep table <전략 id> --out <임시 경로>`로 표를 만들어 본다.
   - 같은 정의의 조합은 자동으로 건너뛰므로 중복을 걱정하지 않아도 된다.
4. **조합을 제안한다.**
   - 한 번에 한두 개 파라미터만 바꾼다. 여러 개를 동시에 바꾸면 무엇이 효과를 냈는지 알 수 없다.
   - 기간은 전체 기간 하나와 구간 몇 개(보통 3~4개)를 함께 넣는다. 구간은 서로 겹치지 않게 나눈다.
   - 한 번에 200회(조합 × 기간)를 넘기지 않는다. 한 번 계산은 약 1초다.
   - 제안에는 조합 수, 기간, 바꿀 파라미터와 값, 고른 이유를 쓴다.
5. **요청 파일을 만든다.**
   - `backend/sweeps/<전략 id>/requests/<YYYYMMDD>-<설명>.json`에 저장한다. 형식은 `backend/README.md`의 "조합 탐색 > 요청 파일"을 따른다.
   - 보고서의 `sweep-request` 블록을 실행하는 경우에도 그 JSON을 이 경로에 저장해 쓴다.
6. **미리 본다.**
   - `uv run python -m app.sweep run <요청 파일> --dry-run`으로 실행할 조합 수와 건너뛸 조합 수를 확인한다.
7. **실행한다.**
   - `uv run python -m app.sweep run <요청 파일>`
   - 분봉을 처음 받을 때는 수 초에서 수십 초 걸린다.
8. **보고한다.**
   - 실행·건너뜀·실패 건수와 실패 원인, 걸린 시간을 알린다.
   - 결과에 대한 판단은 하지 않는다. 비교와 추천은 `sweep-report`로 넘긴다.

## 하지 않는 일

- 전략 코드, `manifest.json`, 이미 있는 `results.jsonl`·거래 파일을 수정하지 않는다.
- `backend/.env`와 키·토큰을 읽어 출력하지 않는다.
- 모의가 아닌 환경(`TRADING_ENV=real`)으로 실행하지 않는다.
- 사용자가 확인하지 않은 큰 탐색(200회 초과)을 시작하지 않는다.
- 결과 좋은 조합을 찾으려고 같은 질문을 계속 조합만 바꿔 반복하지 않는다. 시도가 많을수록 우연히 좋은 조합이 나오므로, 새 탐색에는 이유를 둔다.

## 실패했을 때

| 증상 | 조치 |
| --- | --- |
| `NH_..._KEY 환경변수를 설정하세요` | `backend/.env`에 키가 필요하다고 사용자에게 알린다. 키를 만들거나 채우지 않는다 |
| `분봉 데이터가 없습니다` | 기간이 가능 기간 밖이다. `range`로 다시 확인한다 |
| `파라미터 ... 이상이어야 합니다` | `manifest.json`의 `min`/`max` 안으로 값을 고친다 |
| 일부 조합 실패 | 나머지는 저장됐다. 실패 원인을 보고하고 같은 요청 파일을 다시 실행하면 성공한 조합은 건너뛴다 |
